Integrity onlyHashing provides integrity verification — detecting unauthorized changes to data. A plain hash alone provides neither confidentiality, authentication, nor nonrepudiation. Hashing and digital signatures together are among the most frequently tested cryptography concepts on the CISSP exam; know exactly which security property each tool delivers.

DeterministicDeterministic: the same input always produces the same output, every time. The same input yields an identical fixed-length digest, enabling reliable integrity comparison between original and received files. [Q136]
One-wayOne-way (preimage resistance): hashing algorithms use one-way mathematical functions producing fixed-length digests, making it computationally infeasible to reverse-engineer or derive the original input from the hash output. [Q1028]
Second preimageSecond preimage resistance: an attacker cannot find a different input that produces the same hash as a specific given input. Distinct from collision resistance, which concerns finding any two distinct colliding inputs — an exam distinction worth memorizing.
Collision resistanceCollision resistance: it is computationally infeasible to find any two distinct inputs producing the same hash output. This is the most critical hash property for verifying stored data integrity — it prevents substitution of a different file having a matching digest. [Q605]
