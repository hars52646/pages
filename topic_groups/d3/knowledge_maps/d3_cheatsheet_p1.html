One shared key both waysSymmetric encryption uses a single shared secret key for both encryption and decryption. It is fast and scalable for bulk data, making it the workhorse of confidentiality in virtually every modern system. It provides confidentiality only and creates the key distribution problem that drives hybrid cryptography design. [Q1115]
Block or stream unitBlock ciphers encrypt fixed-size blocks (e.g., 128-bit); stream ciphers encrypt 1 bit/byte at a time. Block examples: AES, DES, 3DES, Blowfish, Twofish, IDEA. Stream examples: RC4, ChaCha20, Salsa20; RC5/RC6 are flexible block ciphers.
Bulk or real-timeBlock ciphers suit bulk data, files, and disk encryption; stream ciphers suit real-time, streaming, low-latency use such as Transport Layer Security (TLS) and virtual private network (VPN) traffic. [Q498]
Padding or nonceBlock ciphers need padding plus a mode of operation; stream ciphers need a nonce/keystream that is never reused. Block ciphers typically use Feistel or substitution-permutation structures; stream ciphers XOR plaintext with a pseudorandom keystream.
AES specs by heartAdvanced Encryption Standard (AES, aka Rijndael) is the current standard (FIPS 197): 128-bit block; 128/192/256-bit keys; 10/12/14 rounds respectively. Uses a substitution-permutation network (SPN), not Feistel.
DES broken howData Encryption Standard (DES) is a 16-round Feistel block cipher with a 64-bit block and only a 56-bit effective key; it is broken — brute-forceable.
3DES effective strengthTriple DES (3DES) uses a 64-bit block with 112- or 168-bit keys (three DES operations) but meet-in-the-middle attacks cap effective strength at 112 bits; deprecated by NIST with a 2023 sunset. [Q518]
Blowfish key schedule...Blowfish is a legacy 64-bit-block Feistel cipher with 32-448-bit keys and a slow key schedule; Twofish (128-bit block) is its successor.
IDEA PGP eraIDEA is a legacy 64-bit block cipher with a 128-bit key, remembered from the Pretty Good Privacy (PGP) era.
RC4 allowed in TLSRC4 is a stream cipher with variable key size; it is broken and prohibited in TLS.
RC6 AES finalistRC5/RC6 are proprietary (RSA Labs) block ciphers with parameterized block, key, and round sizes; RC6 was an AES finalist.

Salsa20 relationSalsa20 is a stream cipher with 256-bit keys and is the predecessor of ChaCha20.

ECB red flagElectronic Codebook (ECB) mode encrypts identical plaintext blocks into identical ciphertext, leaking data patterns. Never use ECB — flag it as insecure whenever it appears in a design.
CBC needs IVCipher Block Chaining (CBC) chains blocks by XORing each plaintext block with the previous ciphertext block; it requires an initialization vector (IV).
CTR parallelizableCounter (CTR) mode combines counter plus nonce to turn a block cipher into a stream; it is parallelizable.
GCM adds whatGalois/Counter Mode (GCM) is Authenticated Encryption with Associated Data (AEAD): CTR plus an authentication tag, providing authenticated encryption (confidentiality plus integrity); widely used in TLS. [Q81 Q1110]
CCM used whereCCM combines CTR plus CBC-MAC for AEAD authenticated encryption; used in WPA2 and IoT.

Confidentiality plus...When a mode must provide confidentiality AND integrity, choose GCM or CCM (AEAD), not CBC alone.
