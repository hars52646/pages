Recall KeySynthesized Explanation
Seven layersThe OSI (Open Systems Interconnection) model is a seven-layer reference architecture that standardizes network communication between systems. The CISSP exam repeatedly tests the ability to map a security function, protocol, or attack to the correct OSI layer, making layer-by-layer mastery non-negotiable.
Layer 7Layer 7 (Application) handles resource access and application services. Key protocols/devices: HTTP/S, DNS, SSH, FTP, SMTP, and application firewalls. In the TCP/IP model it maps to the single Application layer (the 4th TCP/IP layer counting from the bottom).
Layer 6Layer 6 (Presentation) handles data formatting, encryption/decryption, and compression. Standards: XML, JPEG, ANSI. TCP/IP collapses it into the Application layer. Exam cue: when asked where encryption or data formatting occurs, choose Layer 6.
Layer 5Layer 5 (Session) manages session management and interhost dialogue control. Example control: circuit-level proxy firewall (SOCKS). TCP/IP collapses it into the Application layer.
Layer 4Layer 4 (Transport) provides end-to-end connection, error detection and correction, and port numbers. Protocols: TCP/UDP, iSCSI. Maps to TCP/IP Transport layer (3rd from bottom). Exam cue: end-to-end error correction, reliability, or port numbers → Transport.
Layer 3Layer 3 (Network) provides logical addressing (IP), routing, and packet delivery. Devices: routers, packet-filtering firewalls. Protocols: IP, ICMP, IPsec. Maps to TCP/IP Internet layer (2nd). Exam cue: routing, IP addressing, or packet filtering → Layer 3.
Layer 2Layer 2 (Data Link) provides physical (MAC) addressing, frame delivery, and switching. Devices: switches, bridges. Protocols: ARP, L2TP, PPTP. Maps to TCP/IP Link layer. Exam cue: MAC-based forwarding, switching, or ARP resolution → Layer 2.
Layer 1Layer 1 (Physical) transmits binary bits over media. Devices: hubs, NICs (network interface cards), cabling, RF (radio frequency). Maps to TCP/IP Link layer. If a device cannot transmit any data at all, troubleshoot Layer 1 first because every higher layer depends on raw bit transmission. [Q165]
OSI 5-7 collapse whereThe TCP/IP model collapses OSI Layers 5-7 (Session, Presentation, Application) into a single Application layer, giving TCP/IP four layers: Link (maps OSI 1-2), Internet (OSI 3), Transport (OSI 4), Application (OSI 5-7). Expect mapping questions between the two models.
Headers down, stripped upEncapsulation wraps data with headers moving down the stack: Segment (L4) → Packet (L3) → Frame (L2) → Bits (L1). Decapsulation strips headers moving up the stack. Each layer only reads its own header, which is why a device can only act on information at its own layer.
Routing questionExam decision rule: any question about routing, IP addressing, or packet filtering maps to Layer 3 (Network). Routers and packet-filtering firewalls operate here because they act on IP addresses.
Reliability questionExam decision rule: questions about end-to-end error correction, reliability, or port numbers map to Layer 4 (Transport). TCP provides reliable delivery; UDP does not.
MAC questionExam decision rule: questions about MAC-based forwarding, switching, or ARP resolution map to Layer 2 (Data Link), where MAC addresses and ARP resolution live.
Encryption formattingExam decision rule: questions about where encryption/formatting occurs map to Layer 6 (Presentation), which transforms data for the application including cryptographic formatting. topology mattersPhysical-layer topologies and media are foundational because every security control — segmentation, redundancy, interception risk — is constrained by the topology and cabling beneath it. The exam tests reasoning about failure modes, cost trade-offs, and interception/tapping risk at Layer 1.
BusBus topology places all devices on one central wire. The entire wire is a single point of failure, and any connected device can intercept all traffic. It is the least secure topology and makes fault isolation difficult.
StarStar topology connects all devices to a central device (switch/hub); if the central device fails, all network communication stops. It is the most common modern LAN topology — cost-effective with centralized management, but always identify the central device as the single point of failure in exam scenarios. [Q197 Q198]
RingRing topology is a closed loop — essentially a bus in a circle. A break in the ring disrupts all devices. It uses token passing: only the token-holding device may transmit, preventing collisions through controlled sequential access. [Q196]
MeshMesh interconnects every node, providing the highest redundancy at the highest cost. Choose mesh when a question asks for maximum redundancy, fault tolerance, or resilience regardless of cost.
TreeTree topology uses hierarchical branches; branches isolate transmission segments, providing moderate isolation between branches.
Full mesh formulaFull mesh connects every node to every other node, requiring n(n−1)/2 links. Best redundancy, most expensive, least scalable — link count grows quadratically with nodes.
Partial meshPartial mesh trades off redundancy against cost and is the practical enterprise choice when full-mesh expense and scalability limits are unjustified.
UTP risksUTP (unshielded twisted pair) uses electrical signaling; it is cheap and common but susceptible to EMI (electromagnetic interference) and crosstalk, and it is easy to tap.
STP vs UTPSTP (shielded twisted pair) adds a foil shield that reduces interference, making it better than UTP against EMI — but it is still copper media and retains copper's residual risks.
Coax security noteCoaxial cable (electrical, used for cable TV/broadband) is a shared medium and can be tapped.
FiberFiber optic uses light pulses, offers the highest speed and longest distance, and is the hardest media to tap without detection — the most secure media. Choose fiber when security against tapping/EMI or maximum distance/speed is the priority.
connector, which mediaRJ-45 connects UTP/STP; BNC connects coaxial; LC/SC/ST/MTRJ are fiber optic connectors.
twisted pair twistsTwisted pair works because the twist cancels electromagnetic interference; copper media is nonetheless inherently vulnerable to crosstalk.
Most secure transmissionUnicast is one-to-one transmission and the most secure method — only the intended recipient sees the traffic. Choose unicast over multicast or broadcast when minimizing interception risk is the goal.
Multicast exposureMulticast is one-to-many transmission to a subscribed group — moderate exposure between unicast and broadcast.
Least secure transmissionBroadcast is one-to-all on the segment: least secure, increasing both interception exposure and traffic load.

breaks broadcast domainsA broadcast domain is a group of devices receiving the same broadcast. Routers (Layer 3) break broadcast domains; switches and hubs do not.

Switch vs router splitA switch is Layer 2: forwards by MAC address and creates collision domains per port. A router is Layer 3: forwards by IP address and creates/separates broadcast domains. Switches segment collisions; routers segment broadcasts.
L3 switchAn L3 switch combines switching and routing but does not inherently enforce security policy — it segments logically, not securely. Logical segmentation alone is not enforcement.
VLANA VLAN (Virtual LAN, IEEE 802.1Q) provides logical segmentation at Layer 2 via a Layer 3 switch, reducing broadcast traffic and isolating hosts — but it is not a security boundary by itself; VLAN hopping is a real attack. Add a firewall for enforcement.
Proxy performance costA gateway/proxy is a Layer 7 intelligent intermediary that inspects payloads. Cost: one proxy is required per service, creating a performance penalty.

TCP profileTCP (Transmission Control Protocol) is connection-oriented with guaranteed delivery via sequence numbers and ACKs (acknowledgments), sequenced in-order reassembly, but slower due to handshake/ACK overhead. Header size: 20 bytes. Uses: HTTP/S, FTP, SSH, SMTP, DNS zone transfers.
UDP profileUDP (User Datagram Protocol) is connectionless, best-effort with no delivery guarantee, no ordering, and faster because there is no handshake or ACKs. Header size: 8 bytes. Uses: DNS queries, streaming video, VoIP, DHCP, TFTP.
TCP vs UDP session...Security implication: TCP's larger header (sequence/acknowledgment numbers) enables better session tracking and verification, whereas UDP's small connectionless header lacks these mechanisms. [Q175]
Three-way handshake orderTCP connection establishment: client sends SYN (with Initial Sequence Number) → server replies SYN-ACK (acknowledging and sending its own ISN) → client sends ACK → full-duplex session established. [Q176]
Sequence numbers do whatTCP sequence numbers uniquely identify each byte's position, enabling reassembly, retransmission, and loss recovery; they also protect against session hijacking and ensure correct packet order because every injected packet must carry the correct sequence value to be accepted.
